# DevLinks 🔗

Página de links pessoal (estilo "link na bio"), feita como projeto final do **Discover**.

## 💻 Sobre o projeto

O DevLinks reúne em um só lugar os meus principais links: GitHub, portfólio, projetos e redes sociais.

Funcionalidades:

- Perfil com foto, nome e usuário
- Lista de links com efeito de hover
- Ícones de redes sociais
- **Light mode / Dark mode** com botão de alternância
- **Layout responsivo** com media queries
- **Animações** de entrada em CSS

## 🚀 Tecnologias

- HTML
- CSS (Flexbox, variáveis CSS, media queries, animações)
- JavaScript
- Git e GitHub
- [Ionicons](https://ionic.io/ionicons) para os ícones

## ▶️ Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/devlinks.git
   ```
2. Abra o arquivo `index.html` no navegador.
